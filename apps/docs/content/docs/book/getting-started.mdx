fossil is a small language for turning tables into a graph. You point it at the data you have and at
a document describing the graph you want, and it writes the graph.

## Install

fossil is one binary, built from the repository:

```bash
cargo install --git https://github.com/Kanzo-Tech/fossil-lang fossil-cli
```

That puts `fossil` on your path. Check it:

```bash
fossil --version
```

## Check it

`fossil check` reads the program, the shape document and the CSV, and tells you whether they agree.

```bash
fossil check hello.fossil
```

```
ok — no errors in hello.fossil
```

One line and an exit code of zero mean they do. If they do not, you get a diagnostic pointing at the
line — that is [When it does not compile](/docs/book/diagnostics), and it is worth reading early.

## Run it

```bash
fossil run hello.fossil --dest file:///tmp/hello
```

```
wrote 1 vertex type(s), 0 edge type(s) to file:///tmp/hello
```

Under `/tmp/hello` is a corpus: columnar files and a manifest, three `Person` nodes in them, one per
row of `people.csv`. There is nothing between `run` and that directory — no build step, no
intermediate object, nothing of fossil's own for you to keep.
