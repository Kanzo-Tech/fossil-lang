fossil is two things, and not having decided that is part of the problem it is now solving. It is a
**mapping language** — you declare how tabular and RDF sources become a property graph, and it type
checks, diagnoses and lowers that declaration. And it is a **corpus compiler** — it executes the
mapping and writes a graph corpus you can address by byte range from anywhere, with no server in
the path.

This site documents where that is going. Every page keeps two registers apart and marks which one
it is in:

and `apps/docs/content.test.ts` fails the build rather than trust anyone to remember.

## Three layers, and the axis is what a piece of code may know

The organising axis is not subject matter. It is **what a piece of code is allowed to know**, and
the sharpest version of that constraint is where the code runs, because that is the only axis on
which the hard requirements actually conflict.

Three destinations have to work — a native command, wasm in a browser, and a product embedding the
language — and the corpus has to be writable with no ceiling on size. Those demands contradict each
other the moment they are read as *"run the engine here"*: wasm32 has roughly 4 GB of address space
and **nowhere to spill**. A browser cannot be larger-than-RAM. That is the substrate, not the code.

So each layer gets a different promise. [Three hosts](/docs/design/three-hosts) is the argument;
this is the shape.

<Steps>

<Step>

### The language layer knows no engine

Parsing, types, name resolution, diagnostics, elaboration into the operator algebra, and the
language server that surfaces all of it.

**No dependency on an execution engine.** That single negative fact is what lets the language server
start in milliseconds and compile to wasm without dragging a database behind it — and it is what
makes the checker in a browser tab the same checker rather than a reduced imitation of it.

</Step>

<Step>

### The compiler layer has a disk, and it declares a budget

Takes the elaborated program and the sources and produces the corpus. **"No ceiling" lives here and
only here**, and it is reachable precisely because this layer has a disk: a declared memory budget,
and spill when the budget bites. A layer without a disk cannot promise that, which is why the
promise must not live in a layer the browser shares.

</Step>

<Step>

### The reader addresses bytes, and does not run programs

Reads the manifest, works out which byte ranges the camera is asking for, hands Arrow to the canvas.
**No dependency on an execution engine** here either. Compiling the engine into the browser is a
claim that the browser runs programs, and [the camera is addressed, not
queried](/docs/characteristics/verbs).

</Step>

</Steps>

### The rule, and its guard

> A crate may depend on its own layer and on the ones beneath it. Never upward, and never on an
> engine its layer does not declare.

Checked, not agreed — a `cargo-deny` `wrappers` entry banning `duckdb` outside the compiler layer,
and `datafusion` outside it too.

<Callout type="warn" title="True today: the guard is written, was run, and is switched off">
It was written and executed on 2026-08-05 and it came out **red**. What it caught on the first
attempt is that `fossil-wasm` — the reader — reaches the engine transitively, through
`fossil-ide → fossil-engine`, while its own `Cargo.toml` says *"NOT pull `fossil-runtime` or any
native UDF crate (Pitfall 3)"*. The rule had been written as a comment the whole time and the graph
broke it anyway.

It is not left enabled because `deny` is a hard CI gate and today it would break the branch for
everyone. `deny.toml` on disk carries the advisory, licence and four-crate ban list, and **not** the
layering rule. Turning it on is the first task, not a side effect of it: the day it passes, the
work is finished.
</Callout>

That gap is the shape of the whole project right now. Twenty-four crates whose boundaries were drawn
by **topic**, when what separates them is what each one may know — `fossil-mcp` is tooling and
carries an engine; so does `fossil-cli`. The design did not bend because of a bad decision. It bent
because of a decision nobody took.
