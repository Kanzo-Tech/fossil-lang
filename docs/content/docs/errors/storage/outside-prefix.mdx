---
title: Outside the vended prefix
description: "`storage/outside-prefix` — a location that no prefix the host vended covers, so no credential may be used to reach it."
---

fossil was asked to read or write a location, and none of the credentials vended for the scope has a
prefix it lies under. A connection vended `s3://b/lake/` and a file at `s3://b/other/x.csv` was asked
for:

```text
s3://b/other/x.csv lies outside any prefix the host vended
```

A host sees `data: { location, prefix }`. Where one credential was being applied, `prefix` is that
credential's; where fossil looked across everything granted, it is the phrase *any prefix the host
vended*. The mount in `@fossil-lang/storage` throws it from `name` and `files`, with the prefixes it
holds, joined, as `prefix`. The same check in
`fossil-storage` reaches a host from `storageName`, as a file's `problem` in a storage read — which is
how a document resolved through a connection reports it — and from a run's reads and writes.

## Why fossil refuses it

The credential is scoped to its prefix, and **nothing in fossil can widen it**: the store enforces the
prefix, and fossil checks it first. The check is not a courtesy. A DuckDB secret is scoped to the
prefix it was installed for, so a read of a location outside it would go out with no secret at all —
anonymously — and fail later as something unrelated, or succeed against data the host never meant to
expose. Refusing by name keeps the host's authorisation the only thing that decides what is read. See
[storage is reached by a vended credential](/docs/design/three-hosts).

## How to repair it

- **Make the connection map and the credentials agree.** `@name/…` expands against the base the host's
  `connections()` gives for `name`; the credential `credentials({ connection: name }, …)` vends must
  have a prefix that base lies under.
- **Vend a credential that covers the location**, or a wider prefix, if the host means to allow it.
- **Check the location.** A path that climbs out of its directory, or names a different bucket or
  container than the connection's, is outside by construction.
