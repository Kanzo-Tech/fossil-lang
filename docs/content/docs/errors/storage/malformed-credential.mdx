---
title: A credential is malformed
description: "`storage/malformed-credential` — the host vended a credential fossil cannot parse: a prefix that is not a directory, or a key missing or not in its expected form."
---

The host vended a `StorageCredential`, and fossil could not turn it into access. The message names
the prefix, the key and what is wrong with it:

```text
the credential for s3://lake/jobs/7/ is malformed: `client.region` is missing
```

A host sees `data: { prefix, key, reason }`. The reasons `fossil-storage` gives are:

| `key` | `reason` |
| --- | --- |
| `prefix` | names a directory and must end in `/` |
| `s3.access-key-id`, `s3.secret-access-key`, `client.region`, `adls.sas-token.<host>` | is missing |
| `s3.session-token-expires-at-ms`, `adls.sas-token-expires-at-ms.<host>` | is not milliseconds since the epoch |
| `s3.path-style-access` | is not `true` or `false` |
| `s3.endpoint` | is not an http(s) URL with no path |

A wrong value is quoted in the reason; a secret key is only ever reported missing, so its value never
appears. The credential is parsed in one place, `Grant::try_from`, and the error reaches a host from
every door that parses one: `mount` (so `open(job, …)`) throws it, a run throws it, and a storage read
answers it as the file's `problem`.

## Why fossil refuses it

The credential is Iceberg REST's `StorageCredential` verbatim, keys and all, and fossil parses it once
into everything it derives — a DuckDB secret, an Azure lease, an `object_store` store, and the time to
renew ([storage is reached by a vended credential](/docs/design/three-hosts)). A missing key or an
unparseable expiry would otherwise surface much later as a store's own error, and an expired or
unsigned request in DuckDB-WASM reads as *no files found*, indistinguishable from absent data.
Refusing at parse time names the key while the host can still fix it.

## How to repair it

- **Fix the key `data.key` names**, in the form the reason asks for. For S3, `s3.access-key-id`,
  `s3.secret-access-key` and `client.region` are required; for an `abfss://` prefix,
  `adls.sas-token.<account>.dfs.core.windows.net` is.
- **End the prefix in `/`.** A prefix names a directory, and every locator is matched against it as
  one.
