---
title: Not a shape this program declares
description: "`name/unknown-shape` — a mapping header, an edge or a field's `Ref<…>` names a type the program neither declares nor imports."
---

A mapping header says which type it produces, and that type is a name the program has: one it
declares (`@iri("…") type Person`) or one it imports (`type { … } := io.shex(…)`). A header naming
anything else has nothing to be checked against:

```fossil
type { Person, Order } := io.shex("shop.shex")
User := io.csv("data/users.csv")
// the binding introduces Person, not Persn
Users : Persn from User
    @subject = "https://shop.example/user/{User.email}"
    email    = User.email
```

```text
`Persn` is not a shape this program declares
help: did you mean `Person`?
```

The same code is raised for an edge, `buyer = Person(User.email)`, when `Person` is no type of the
program, so there is no identity to build; and for a declared field's `Ref<Town>` when `Town` is
none, so there is no node to refer to.

## Why fossil refuses it

The shape is the contract a mapping body is checked against: which properties may appear, what each
holds, how many. Without one, every property line would be unchecked, and the program would compile
into triples nobody had agreed to. A header cannot name a shape IRI or reach into the document
directly; it names a bare name the program introduced — a declaration, or [an import by the
shape's local name](/docs/book/what-you-produce#importing-by-name). So the only thing a header can
get wrong at this point is the name, and the suggestions are drawn from the names the program has,
not from the IRIs a document declares.

A name the program does introduce but which resolves to nothing is reported by its cause instead — an
import with no document is [`shape/no-document`](/docs/errors/shape/no-document), and one naming a
shape its document does not declare is [`shape/not-in-document`](/docs/errors/shape/not-in-document)
— so this code means only what its title says.

## How to repair it

- **The name is misspelt.** The `help` suggests the nearest bound name; when none is near, it lists
  every name the program binds.
- **The type is not there yet.** Declare it, or add the shape's local name to a `type { … }` import.
- **The program has no types at all.** The `help` says so; declare one, or import one with
  `type { … } := io.shex("…")`.
